Malina help

Recover an edit

Use File → Local Recovery to open a recovery copy, then save it with a new name. Open tabs and drafts also return after relaunch. Recovery is local; keep your own backups of important files.

A file changed outside Malina

Use Save a Copy to preserve your edits. Reload from Disk replaces the editor with the external version and clears undo history, keeping a local recovery copy first.

An image is missing

Keep the Markdown file and its images folder together. In the App Store version, choose File → Image Folder Access and select the folder containing the document. A relative image path is resolved from that folder.

Supported formats

Malina edits Markdown (.md, .markdown, .txt) and Fountain (.fountain). It reads UTF-8 and UTF-16 files with a byte-order mark. It does not open Word, RTF or PDF as editable documents. PDF and HTML are export formats.

Keyboard shortcuts

⌘N: new tab. ⌘O: open. ⌘S: save. ⌥⇧⌘S: save as. ⌘J: find a section. ⌘1/2/3: write, read, source. ⌘F: find. ⌥⌘F: replace. ⇧⌘E: PDF export.

Before reporting a problem

Note the Malina version from About Malina, your macOS version, and the steps that reproduce the problem. Use a small anonymous copy of a document; do not share private writing unnecessarily.
